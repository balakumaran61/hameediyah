# Hameediyah Restaurant · The Pole That Never Rested

A concept website for Hameediyah, Penang's oldest nasi kandar restaurant (164A Lebuh Campbell, since 1907), made for an internal UI/UX and frontend challenge. Not affiliated with the restaurant.

| Folder | What's in it |
|---|---|
| `site/` | The website: Vite, React, TypeScript, Tailwind CSS, GSAP |
| `wireframes/` | Phase 1 wireframes and user flow (open `wireframes/index.html`) |
| `docs/RATIONALE.md` | Design and strategy rationale |
| `docs/design/` | Design tokens, style tile and high-fidelity screens |
| `submission/` | The submission entry |

## Run locally

```bash
cd site
npm ci
npm run dev
```
